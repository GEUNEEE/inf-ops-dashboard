# 영끌러님 대시보드 설계 (2026-10-07)

## 1. 목적

직원 1인(영끌러님)이 담당하는 인플루언서·메일 발송·그로 인한 매출만 따로 보여주는 대시보드를
기존 종합 대시보드와 **동일한 모양으로 복제**해 만든다. 종합 대시보드는 그대로 두고(전체 수치 포함),
영끌러님 몫은 엑셀의 `ㅇ` 표시로 구분한다. 제품은 흑염소 · 수면영양제(슬립이지) · 화장품(스팟멜트크림) 3종 모두 반영한다.

## 2. 데이터 소스와 "영끌러님 몫" 판정

| 데이터 | 파일 | 영끌러님 판정 | 제품 판정 |
|---|---|---|---|
| 인플루언서 상태·일정 | `G:\…\스카이님 공유용 스프레드 개설\인플루언서 종합 관리시트.xlsx` 시트 `인플루언서관리` (전치형, 열=인플루언서) | A열 라벨 **"영끌러님 관리"** 행에 `ㅇ` | A열 라벨 **"제품"** 행 (사장님이 추가·입력: 흑염소 / 화장품 / 수면) |
| 메일 발송 퍼널 | ① `1. 유튜브 인플루언서 관리_공유_*.xlsx` ② `1. 뷰티 인플루언서 관리_공유_*.xlsx` ③ `1. 슬립이지 인플루언서 관리_공유_*.xlsx`(신규) — 각 파일의 `메일발송현황*` 시트 | 6행 헤더 **"구분"** 열(맨 앞, 분류 앞)에 `ㅇ` | 파일 종류로 고정: 유튜브=흑염소, 뷰티=화장품, 슬립이지=수면영양제 |
| 매출·수량·정산 | `C:\Users\user\비서\스케줄\정산DB_업데이트.xlsx` `Raw_Data` | `유튜버 이름`(name_map 정규화 후)이 ㅇ 인플루언서 명단에 포함 | `제품` 컬럼 |

규칙
- `ㅇ` 판정: 셀 값 공백 제거 후 `ㅇ`, `o`, `O`, `○` 중 하나.
- 제품 값 정규화: `수면`·`슬립이지`→`수면영양제`, `스팟멜트`→`화장품`. 비어 있으면 Raw_Data 주문의 제품으로 추정, 그래도 없으면 `미지정`(요약 탭 집계에는 포함, 제품 탭에는 "제품 미지정 N명" 안내로 표시).
- 파일 선택: 패턴 `<종류> 인플루언서 관리_공유_(\d{6})`, `~$`·`백업` 제외, 날짜 최신 1개. 슬립이지 파일이 아직 없으면 경고 후 해당 제품 퍼널은 0으로 둔다.
- 시트 선택: 이름이 `메일발송현황`으로 **시작**하는 시트 (뷰티 파일은 `메일발송현황(미니 대시보드 수식 수정 필요)`).
- 열 선택: 6행 헤더 글자로 찾는다 (`구분`, `채널명`, `발송일`, `확인일`, `회신일`, `진행 상태`, `미팅일`, `협찬 수락일`, `광고 수락일`). 열 번호 고정 금지.
- 행 선택(종합 관리시트): A열 라벨 글자로 찾는다 (`현재 상태`, `유튜버명`, `영끌러님 관리`, `제품`, `체험 수락일`, `1차 광고` 등). 행 번호 고정 금지 — 사장님이 행을 추가해도 깨지지 않게.

## 3. 엑셀 1회성 변경 (실행 전 각 파일 `_backup_YYMMDD` 복사본 생성, Excel COM으로 수행해 필터·병합 자동 보정)

1. **뷰티 파일** `메일발송현황*` 시트: `A6:A<마지막행>` 범위에 셀 삽입(오른쪽 이동), `A6="구분"`. 1~5행 미니 대시보드는 그대로 둔다. 기존 `분류`(인스타) 값은 B열로 밀려 보존.
2. **유튜브 파일** `메일발송현황` 시트: 동일하게 `A6:A<마지막행>` 삽입, `A6="구분"`.
3. **슬립이지 파일 신규 생성**: 뷰티 파일을 복사해 `1. 슬립이지 인플루언서 관리_공유_261007.xlsx`로 저장. 시트명은 접미사 없이 `메일 변환` / `메일발송현황` / `인플루언서관리` / `메일 답장 메뉴얼`. `메일발송현황` 7행 이하 데이터와 `메일 변환` 7행 이하 데이터는 비우고 헤더·수식·`구분` 열은 유지. `메일 변환` C3/D3 제목·내용 템플릿과 `메일 답장 메뉴얼` 문구는 뷰티 것이 남아 있으므로 **사장님이 슬립이지용으로 수정**(인수인계 항목).
4. 종합 관리시트는 건드리지 않는다 (`제품` 행은 사장님이 추가).

열 삽입의 파급 범위와 대응
- `parse_mail.py`(종합 파이프라인, 열 번호 고정) → 헤더 기반 열 탐색으로 수정. 수치 변화 없음.
- `merge_influencer.py` → 헤더 기반이라 수정 불필요.
- `db-sync/sync_core.py` 상수(`MAIL_NAME=4, MAIL_URL=5, MAIL_OWNER_COLS={0:"분류"}`) → +1 보정만 해 둔다(예약작업은 계속 비활성).
- claude.ai 동기화 스킬 `send-date-input`(E열 색상·Z열 발송일), `mail-conversion-workflow`(C/D/E열)는 여기서 수정 불가 → **F열·AA열로 바뀜을 사장님께 안내**.

## 5. 영끌러님 대시보드 화면 (복제 + 최소 조정)

- 탭: 요약 / 흑염소 / 수면영양제 / 화장품 (ytber_config `products`에서 생성, 올리브오일캡슐은 ㅇ 매출이 0이면 숨김).
- **요약 탭 최상단에 "이번 달 운영 현황" 한 줄 추가**: `담당 N명 │ 발송 → 회신(%) → 미팅 → 체험 → 광고` + 제품별 미니 카드(발송·체험·매출). 나머지는 기존 요약과 동일.
- **각 제품 탭에 메일 퍼널·인플루언서 카드 표시** (종합은 흑염소 탭에만 퍼널이 있으나, 영끌러님은 3개 파일을 각각 관리하므로 제품별로 보여준다). 레이아웃·카드 디자인은 흑염소 탭 것을 그대로 쓴다.
- 영끌러님 범위 밖이라 제외: 지인판매 카드, 광고 퍼포먼스 페이지, 기타/일반 매출. 데이터가 비면 카드 자체를 숨긴다.

## 6. 데이터 생성 — `build_yk.py` (신규, 기존 스크립트 수정 없음)

위치: `.claude/skills/dashboard-builder/scripts/build_yk.py`. 입력은 §2의 원본 파일과 `ytber_config.json`, 그리고 종합 파이프라인이 이미 만든 `output/tmp/settlement.json`(인플루언서별 정산금·누적수량·구간단가).

출력: `site/yk/data/dashboard.json` — **종합 `dashboard.json`과 같은 키 구조**(`generated_at, current_month, products, stores, revenue, mail_funnel, mail_funnel_by_month, mail_funnel_by_product, inf_status, settlement_month, settlement_summary, trends, ad_by_month, profit_analysis, cosmetics_breakdown, product_trials, manual_sales(빈 배열), alerts, ops_summary(§5 상단 한 줄용)`) + `site/yk/data/influencer/{name}.json`.

계산 원칙
- 매출·수량·수익·추세는 **Raw_Data를 직접 읽어** ㅇ 명단으로 필터한 뒤 월×제품으로 집계한다(history 스냅샷에 의존하지 않음 → 과거 월도 즉시 채워짐). 단가·원가·인건비·VAT·화장품 세트가·체험단 규칙은 `ytber_config.json`의 동일 상수를 쓰고, 계산 함수는 `build_kpi.py`/`build_revenue.py`에서 import해 재사용한다(복제 금지).
- 정산금·누적수량·현재 단가는 종합 `settlement.json`에서 이름으로 필터(재계산하지 않음 → 종합과 불일치 방지).
- 메일 퍼널은 3개 파일을 각각 읽어 `구분=ㅇ` 행만 집계, 파일→제품으로 `mail_funnel_by_product`, 합산이 `mail_funnel`. 집계 규칙(발송일/회신일/미팅일/수락일 월 귀속, 기타 제외)은 `parse_mail.py`와 동일.
- 인플루언서 상태·체험·광고 집계는 종합 관리시트 ㅇ 열만 대상으로 `parse_inf.py`와 같은 규칙.
- 종합 관리시트 ㅇ 명단과 Raw_Data 이름 대조 시 `name_map` 정규화를 거치고, ㅇ인데 Raw_Data에 없는 이름은 매출 0으로 카드만 표시, Raw_Data에만 있고 ㅇ 아닌 이름은 제외.

## 7. 파이프라인 연결 (기존 흐름 유지)

- `run_pipeline.py`: STEP 8 직후 **STEP 8.5** 로 `build_yk.py` 호출(실패해도 종합 배포는 계속, 경고만).
- `parse_inf.py`: 소스 파일을 종합 관리시트로 변경 + 행 라벨 탐색(§2). `managed_set`은 89명 전원(ㅇ 무관) → 종합 수치 영향 없음.
- `parse_mail.py`: 헤더 기반 열 탐색(§3).
- `notify.py`: 카톡 메시지 말미에 `영끌러님: <SITE_URL>yk/` 한 줄 추가.
- `CLAUDE.md` 파일 경로 표·`대시보드 갱신` 트리거 설명에 영끌러님 항목 추가. `dashboard-builder/SKILL.md`에 `build_yk.py` 실행법 추가.
- 배포는 기존 `publish.py`(`git add site/`) 그대로.

1. **회귀**: 변경 후 종합 파이프라인을 `--rebuild`로 돌려 `site/data/dashboard.json`의 `revenue`·`settlement_summary`·`mail_funnel.total_sent`가 변경 전과 동일한지 diff.

4. **수동 대조**: 사장님이 ㅇ 표시한 뒤 샘플 3명의 카드 수치(매출·수량·상태)를 엑셀과 비교.
5. 로컬에서 `site/yk/index.html`을 열어 4개 탭·인플루언서 상세 페이지 렌더 확인 후 배포.
