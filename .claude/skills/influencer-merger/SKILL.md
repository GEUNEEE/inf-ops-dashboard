# influencer-merger 스킬

## 역할
`유튜브_인플루언서_리스트_*.csv(또는 xlsx)` 파일을 읽어
**마스터 DB와 공유 파일 두 곳의 `메일발송현황` 시트에** 신규 행을 추가한다.

- 헤더명 자동 매핑 (채널명·링크·구독자수·조회수·영상수·연락처·키워드·블로그·카페·인스타·쓰레드)
- (채널명, 링크) 기준 중복 자동 제거 — **타겟별로 각자의 기존 시트 기준** + 소스 내부 중복도 제거
- 타겟마다 백업 → append → 행 수 검증 (독립)
- 소스 파일 이동은 **두 타겟 모두 정상 처리된 뒤 1회만** (한쪽이라도 실패하면 소스 유지 = 재시도 가능)

## 파일 구성

| 파일 | 역할 |
|------|------|
| `scripts/merge_influencer.py` | 전체 병합 로직 (소스 수집·타겟별 백업·append·검증·소스 이동) |

## 실행 명령

```powershell

& "C:\Users\user\비서\.venv\Scripts\python.exe" `
  "C:\Users\user\비서\.claude\skills\influencer-merger\scripts\merge_influencer.py"
```

옵션:
- `--source "<경로>"` : 소스 파일 1개만 직접 지정 (생략 시 소스 폴더 전체)
- `--no-move` : 처리 후 소스 파일을 OLD 폴더로 이동하지 않음

## 동작 순서
1. 소스 폴더에서 `유튜브_인플루언서_리스트*` 전체를 수정시각 순으로 수집
2. **마스터** 처리: 백업 → 기존 시트 기준 중복제거 → append → 검증
3. **공유** 처리: 백업 → 기존 시트 기준 중복제거 → append → 검증
4. 두 타겟 모두 검증 통과 시에만 소스 파일을 `_YYMMDD완료` 붙여 OLD 폴더로 이동

## 전제 조건
- 소스 폴더에 `유튜브_인플루언서_리스트*.csv/xlsx` 1개 이상 존재
- 두 타겟 파일이 Excel에서 열려있지 않을 것
- 여러 소스가 있으면 전부 처리(누적 중복제거)

## 에러 처리

| 상황 | 처리 |
|------|------|
| 소스 파일 없음 | 중단 (소스 폴더 확인) |
| 타겟 파일 잠금 (Excel 열림) | 해당 타겟 실패 처리 → 소스 이동 안 함 |
| 행 수 검증 실패 | 해당 타겟 실패 → 소스 이동 안 함, 백업으로 복구 가능 |
| 한 타겟만 실패 | 소스 유지 (이동 X) → 원인 수정 후 재실행 |
| 추가할 신규 데이터 없음 | 정상 (중복 확인 완료) |
